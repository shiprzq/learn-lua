# Contributing

Thanks for helping make Learn Lua better! 🌙

1. Fork the repo and create a branch: `git checkout -b fix-typo`.
2. Keep examples runnable with `lua examples/<file>.lua` on Lua 5.4.
3. Follow the style: 2-space indent, `local` everywhere, `snake_case`.
4. Open a pull request describing what you changed and why.

Ideas welcome: new exercises, translations (Arabic, Spanish, …), diagrams, or chapters on LÖVE, Neovim, or the C API.
